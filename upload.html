Studio uploader.

Add photos to your portfolio or write in your journal. Press Publish and your website updates in about a minute.

1. Connect to GitHub

One-time setup. This is saved in this browser only.

Not connected
  1. Open GitHub → New fine-grained token.
  2. Name it "Studio uploader". Under Repository access, choose Only select repositories and pick your website repo.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Click Generate token, copy it, and paste it below.

2. Add photos

JPG, PNG or WEBP. iPhone HEIC photos work in Safari; in other browsers export them as JPG first.

3. Captions and order

The top photo is the cover, which is the big image on the home page. Categories become filter buttons on the portfolio.
